# CV-S05d census: run-03, the round 13 fix list (2026-10-27)

**Reading:** the same as run-01. **Recall:** 10/10.

## What this run did

1. **Fixed the finder misses** listed in run-02's triage:
   - exception lists' sub-items, and the "Except for …", "apart from …" and "extend to X with the exception of— …" forms;
   - two statements joined by "and" or "but", including the elliptic "and those in …";
   - a verb in the last item;
   - bracketed asides and "outside the UK";
   - same-extent paraphrases;
   - "respectively";
   - sub-ranges: "(4) to (8A)", "(b) to (d)", "15(1) to (19)";
   - sub-letter levels, so "(1A), (2)(b)" is read right;
   - "cease to apply";
   - ". . ." with its comma;
   - "the amendments specified in …";
   - other laws' lists ("The following provisions of the Education Act 2002 cease to have effect …").
2. **Reviewed the over-reach list in full:** 358 refs in 53 laws.
3. **Consolidated the fix list** (`out/triage.md`): 17 wordings in about 65 laws. Each wording has at least one law confirmed with `Extent.of`.
