# Session: Issue #147: Abbreviation-Style Law References (CLOSED)

## Problem

28 definitions reference laws by initialised abbreviation + year (e.g. "TCPA 1990", "EA 1989", "CRA 2015") but no extraction pattern handles this format. These abbreviations are never defined as `citation=true` entries, so the citation_index has no mapping. Needs a new feature — initials matching against title_index or a static abbreviation map.
