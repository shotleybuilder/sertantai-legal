lessons:
  - title: Never use ~w() sigil for multi-word option values
    detail: >
      ~w(Open In\ Progress Completed Cancelled) splits into ["Open", "In", "Progress", ...].
      The backslash escape doesn't work in ~w(). Use explicit list ["Open", "In Progress", ...]
      for any values containing spaces.
    tag: tooling

  - title: Use datetime_picker element type for date fields, not input_text
    detail: >
      Baserow's Update Row action validates field types. Passing a text string to a date
      field fails with "cannot be converted to a date". The datetime_picker element type
      provides a calendar UI and outputs the correct date format.
    tag: baserow

  - title: Don't reference Baserow formula fields in App Builder table columns — build the formula in the column
    detail: >
      Formula fields that reference link_row fields return raw JSON {"id":N,"value":"..."} in
      App Builder table columns. Instead of get("current_record.field_FORMULA"), build the
      display text directly: concat(get("current_record.field_LINK.*.value"), " — ", ...).
      This was also hit in Phase 1 (Law column) but the pattern repeats.
    tag: baserow
