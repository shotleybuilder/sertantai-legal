# Session: Issue #165 PDF → LAT Parser (ACTIVE)

## Problem

Some in-force laws have no XML body on legislation.gov.uk, only metadata and a PDF. Without a body, they can't get LAT, fractalaw enrichment, a Making verdict or a tree. QQ-01 found two in QQ's register: `UK_uksi_1979_791` (Forestry (Felling of Trees) Regs 1979) and `UK_uksro_1947_805` (Compressed Acetylene Order 1947).

**Both PDFs are scanned page images with no text layer.**
- `pdftotext` returns 18 and 2 bytes.
- The pages are 150 ppi JPEGs; the 1947 Order's producer is "Acrobat Image Conversion Plug-in".

So this is an **OCR** problem, not just PDF text parsing. `SecondarySource.PdfParser` reads a PDF's text layer (with font metadata). A scan has no text layer, so OCR is the one missing step in front of the existing classify → persist chain.

## Batch runbook

1. A LAT parse (workflow API or admin) hits a no-body law. Its PDFs land in `backend/data/pdf-backlog/<law>/` and are listed in `manifest.csv`.
2. `mix lat.pdf_backlog` lists the state of each law.
3. For each `needs_transcript` law, render pages with `pdftoppm -r 150 -png <pdf> <prefix>`, then write `transcript.md` in the `Transcript` markup (see its moduledoc):
   - one paragraph per line;
   - `## heading`;
   - `N.—(1)`, `(2)` and `(a)` markers;
   - `> ` for quoted/inserted text;
   - `# SIGNED` and `# SCHEDULE n: title` sections;
   - `<!-- -->` for omitted matter;
   - `[?]` for uncertain readings.

   Omit the preamble, the Explanatory Note and footnote markers. Record prescribed forms as headings.
4. Run `mix lat.pdf_backlog --run --dry-run`, check the row count and QA, then `mix lat.pdf_backlog --run`.
5. Hand the laws to fractalaw (Jason launches).

Transcripts live in the gitignored `backend/data/` (NAS-backed), next to the PDFs. The generated `body.xml` is kept for audit.

Design choice: going via generated legislation.gov.uk-style XML, rather than a separate PDF-to-LAT row builder, means LatParser conventions (and any fixes to them, such as the open schedule-text bug) apply to PDF-sourced laws on re-run.
