# Session: Issue #168, ChangesFeed in-force data (PENDING)

Approved: Jason, 2026-10-01 (fractalaw DRRP-TEMPORAL-PROPOSAL L10, decision D6). Also carries the #167 follow-up (L9, decision D5).

## Problem

L8.4's `effects_unapplied` can't tell an in-force effect whose text application lags (stale text) from a prospective effect that isn't law yet. Fractalaw's L10 rule needs that: unapplied + prospective → never flip; unapplied + a past in-force date → a whole-provision omission/repeal flips to none. legislation.gov.uk's changes feed carries it per `ukm:Effect` (`ukm:InForce` Date | Prospective, Qualification, commencing instrument; `ukm:Savings`; structured `ukm:Section Ref` affected provisions), but legal's ChangesFeed reads only the Effect attributes. Sample anaw/2016/3: all 7 unapplied effects are Prospective.
