## Draft schema (2026-10-19, for Jason)

Today the reader is **row-driven**: for each note on a row, `Target` asks "does this instruction name *this* row?" — every new form (a block, a quoted path, a subsection numbered from the substituted one) is another case in that matcher. The ruleset inverts it: each amending provision is read **once** into a rule saying what it changes; one evaluator says which rows a rule reaches.

| Field | Values | Example |
|---|---|---|
| `amends` | a law name | `UK_uksi_2014_1638` |
| `targets` | refs in LAT grammar, expanded at read time: named provisions, ranges, and the quote's own provisions (a block resolved to what it quotes) | `["reg.69".."reg.76"]` for "For Part 13, Sub-Part C substitute— [regs 69–76]"; `["s.148(3)"]` + quote `[3, a]` → `"s.148(3)(a)"` |
| `operation` | `:inserted` · `:substituted` · `:repealed` | |
| `level` | `:provision` (reaches the rows inside each target) · `:words` (the named row only) | "for “x” substitute “y”" → `:words` |
| `source` | `%{law, ref, text}` — the amending provision read, verbatim | `UK_uksi_2019_696` `sch.16.para.28` |
| `treatment` | `:instruction` · `:repeal_table` | |

Not in the rule: the date (`Commencement.Amending` dates the source provision — the commencement ruleset) and the note (a pointer to which provisions to read, one hop from our rows, never a fact).

**Evaluator:** a rule reaches a row when a target is the row, or — at `:provision` level — an ancestor of it (bracket prefix, container). The collector makes one record per reached row, as now.

## Gemini review (2026-10-19)

Proposed adding `content` (new text / words) and `position` (before / after / at end), merging `operation` + `level` (`:substitute_words` …), `:renumbered`, words on a container reaching every descendant; agreed targets expand at read time, ranges as the commencement evaluator, overlapping changes as independent events, `treatment` provenance only, parallel run + classified diff.

## Decided (Jason 2026-10-19: "Accept")

- **No `content`, no `position`.** We label which rows changed, when and how; we never rebuild text (the revised text is legislation.gov.uk's). Simplify, not complicate.
- **`operation` and `level` stay separate** — "words inserted" is a real change (Gemini's "invalid state" isn't), and the pair matches the register's effect types ("words substituted").
- **Words-level reaches the named provision only** — never inferred onto a container's descendants (markup and notes evidence which rows changed).
- **Accepted:** `:renumbered`; targets expanded at read time; ranges resolved as the commencement evaluator does; overlapping changes are independent events, each dated by its own source; `treatment` is provenance only; parallel run + classified diff, LR-41 benchmark with no regression.

| Field | Values |
|---|---|
| `amends` | the law changed |
| `targets` | refs in LAT grammar, expanded at read time (named provisions, ranges, the quote's own provisions) |
| `operation` | `:inserted` · `:substituted` · `:repealed` · `:renumbered` |
| `level` | `:provision` (reaches the rows inside each target) · `:words` (the named row only) |
| `source` | `%{law, ref, text}` — the amending provision, verbatim |
| `treatment` | `:instruction` · `:repeal_table` (provenance) |

## Rules

- Simplify, not complicate (Jason 2026-10-18, for the commencement ruleset): fields only where a real instruction needs them.
- Notes are pointers, never facts; effects first; every fetch one hop from our rows.
- Iterate on the affected laws; one whole-corpus run per change (Jason 2026-10-19).
