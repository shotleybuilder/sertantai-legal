## Investigation (2026-03-30)

### Root cause (high confidence)

The `createLiveQueryCollection` (used internally by the adapter's `executeGroupSummary`) stores grouped results as objects with this shape:

```
{
  __key_0: "ukpga",           // raw group key from groupBy pipeline
  $selected: {                 // the select() output
    type_code: "ukpga",       // group column value
    _count: 10565             // aggregate
  },
  $synced: true,
  $origin: "remote",
  ...
}
```

GridLite's group tree reads `row[topCol]` (e.g. `row['type_code']`) to build `group.values`. But `type_code` lives inside `$selected`, NOT at the top level. So `row['type_code']` → `undefined` → label shows `(Empty)`.

### Why it works in the dev app

The dev app likely uses `electricCollectionOptions()` or a direct collection (not `createLiveQueryCollection` wrapping a `groupBy`). Need to verify — but the key point is that this is about how `createLiveQueryCollection` stores its output rows from grouped queries.

### Fix options

1. **In the adapter** (gridlite-adapter-tanstack-db): After `toArrayWhenReady()`, unwrap `$selected` from each row before returning. Something like: `rows.map(r => r.$selected ?? r)`. This is the cleanest fix since it's the adapter's job to normalize TanStack DB output.

2. **In GridLite**: Read from `row.$selected[col]` — bad, leaks TanStack DB internals.

### Key files traced
- `@tanstack/db/dist/esm/query/compiler/group-by.js` — `processGroupBy()` puts group column values in `finalResults` under `$selected`, raw keys as `__key_N`
- `@tanstack/db/dist/esm/query/live/collection-config-builder.js` — `applyChanges()` writes the full `resultRow` (including `$selected`) to the collection
- `@tanstack/db/dist/esm/collection/state.js` — `enrichWithVirtualProps()` spreads the stored row, adding `$synced`, `$origin` etc. `$selected` remains nested
- `@tanstack/db/dist/esm/collection/index.js` — `toArrayWhenReady()` returns enriched rows via `values()`
- `@shotleybuilder/gridlite-adapter-tanstack-db/dist/adapter.js` — `executeGroupSummary()` reads `row[g.column]` from result, gets `undefined`
- `@shotleybuilder/svelte-gridlite-kit/dist/GridLite.svelte` — `getGroupLabel()` reads `group.values[col]`, shows `(Empty)` for null/undefined
