## Notes
- Tower hit `transaction_timeout` error: brew libpq 18.3 sends `SET transaction_timeout = 0` which PG 15 doesn't understand
- Root cause: host pg_restore version mismatch, not dump format issue
- Tower: brew libpq 18.3 → PG 15 container. Laptop: apt libpq 15 → PG 15 container (worked fine)
- **Decision**: keep host pg_restore, don't switch to docker exec

  - docker exec cons: NAS/dump files not visible inside container (need stdin pipe), more complex script
  - Keeping host tools is simpler; just keep PG container version in sync across machines
