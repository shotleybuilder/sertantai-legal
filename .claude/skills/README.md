# Skills

Each skill lives in `<name>/SKILL.md`. Its frontmatter `description` is the catalogue: Claude Code lists skills from it, so this README keeps no list of its own (a hand-kept list here drifted badly and was removed 2026-10-24).

To see what exists:

```bash
grep -H '^description:' .claude/skills/*/SKILL.md
```

Background on writing skills: [docs/skills-starter.md](../../docs/skills-starter.md).
